System Overview Updated: Nov 2011

NixelOS is an independent operating system project made to revitalize older machine hardware while offering an array of features you wouldn't have on legacy operating systems.

The OS comes with everything you need to get started, with more utilites to come!

Key Architectural Features

◆ Small Footprint

Operates smoothly in as little as 25 MiB of physical RAM

◆ Full Audio Subsystems

Supports MIDI and MP3/Wav Audio playback on supported hardware

◆ Full network support

Out-of-the-box support for the Intel Gigabit E1000 family, AMD PCNet-PCI adapters, Broadcom BCM4401 controllers, and Broadcom Tigon3 controllers.

◆ Integrated Desktop & Apps

Includes tons of utiltiies and a fully working Desktop Environment
